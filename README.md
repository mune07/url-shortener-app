# 🔗 URL Shortener Service

A full-stack URL shortening application built with **Spring Boot 4** and **Angular 22**, featuring custom aliases, click analytics, pagination, and a clean layered architecture.

Live demo: `http://localhost:4200` (frontend) · `http://localhost:8080/swagger-ui.html` (API docs)

---

## Features

- **Shorten any long URL** into a compact Base62-encoded short code
- **Custom aliases** — choose your own short code (e.g. `/my-portfolio`) with uniqueness and reserved-word validation
- **Duplicate detection** — re-submitting the same URL returns the existing short code instead of creating a new row
- **Click analytics** — tracks total clicks and last-accessed timestamp per link
- **Paginated URL history** — browse all shortened URLs, newest first, loaded from the database on page load
- **Centralized error handling** — structured JSON error responses via `@RestControllerAdvice` instead of raw stack traces
- **Interactive API docs** — Swagger/OpenAPI UI for testing every endpoint directly
- **Responsive UI** — Angular standalone components + signals, styled with Bootstrap 5

## Architecture

```
Angular (standalone components, signals)
        │ HTTP/JSON
        ▼
Spring Boot REST Controllers
        ▼
Service Layer (Base62 encoding, validation, duplicate detection)
        ▼
Repository Layer (Spring Data JPA)
        ▼
MySQL
```

**Design decisions:**
- Short codes are generated by **Base62-encoding the database auto-increment ID**, guaranteeing uniqueness with zero collision risk — no retry loops needed.
- Redirects (`GET /{shortCode}`) live at the **root path**, not under `/api`, matching how real-world shorteners (bit.ly, tinyurl) structure their links.
- A fixed set of **reserved words** (`api`, `admin`, `swagger-ui`, etc.) is blocked from custom aliases to prevent route collisions.

## API Endpoints

| Method | Endpoint | Description |
|---|---|---|
| `POST` | `/api/urls` | Create a shortened URL (optional custom alias) |
| `GET` | `/api/urls?page=0&size=10` | Paginated list of all shortened URLs, newest first |
| `GET` | `/api/urls/{shortCode}/stats` | Click analytics for a specific short code |
| `GET` | `/{shortCode}` | Redirect to the original long URL |

Full interactive documentation available at `/swagger-ui.html` once the backend is running.

## Getting Started

### Prerequisites
- Java 21+
- Node.js + Angular CLI 22
- MySQL 8 (running locally)
- Maven

### 1. Clone the repo
```bash
git clone https://github.com/mune07/url-shortener-app.git
cd url-shortener-app
```

### 2. Configure the database
Update `backend/src/main/resources/application.yml` with your MySQL credentials:
```yaml
spring:
  datasource:
    username: root
    password: your_mysql_password
```
The database `url_shortener_db` and its tables are created automatically on first run.

### 3. Run the backend
```bash
cd backend
mvn spring-boot:run
```
Backend runs on `http://localhost:8080`.

### 4. Run the frontend
In a separate terminal:
```bash
cd frontend
npm install
ng serve
```
Frontend runs on `http://localhost:4200`.

### 5. Open the app
Visit `http://localhost:4200` in your browser.
